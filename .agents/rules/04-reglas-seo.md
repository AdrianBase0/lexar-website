# Reglas de SEO Técnico

## Etiquetas Meta
- Cada página debe tener un `<title>` único optimizado (Formato: "Página | Advance Lexar - Consultoría").
- Cada página debe incluir una `<meta name="description">` de máximo 155 caracteres.
- Configurar `<meta name="viewport" content="width=device-width, initial-scale=1.0">`.

## HTML Semántico
- Respetar la jerarquía de encabezados: Un solo `<h1>` por página, seguido de `<h2>` y `<h3>` lógicos.
- Atributos `alt` descriptivos obligatorios en todas las etiquetas `<img>`.
- Uso de etiquetas `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.

## Datos Estructurados (Schema.org)
- Implementar JSON-LD básico para `LocalBusiness` o `ProfessionalService` en la página de inicio y contacto.
