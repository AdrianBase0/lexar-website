# Reglas de Diseño y Estilo: Advance Lexar

## Identidad Visual y Paleta de Colores
Extraída del logotipo corporativo (consultoría estratégica). Usar las siguientes variables CSS en el `:root`:
- `--color-base-dark`: `#3b2c24` (Marrón muy oscuro, casi negro. Usar para textos principales y bordes).
- `--color-arrow-top`: `#7d4334` (Marrón rojizo. Usar para elementos de destaque secundarios).
- `--color-arrow-mid`: `#e5ce83` (Dorado/Mostaza. Usar para detalles, hover o fondos de secciones destacadas).
- `--color-arrow-bot`: `#d28b46` (Naranja tierra. Usar para llamadas a la acción o botones principales).
- `--color-bg-light`: `#ffffff` (Blanco para fondo principal).
- `--color-bg-alt`: `#f9f8f6` (Blanco roto cálido para diferenciar secciones).

## Tipografía
- **Títulos (Headings)**: Usar una fuente Serif clásica y elegante que transmita autoridad (ej. 'Playfair Display', 'Merriweather' o Georgia como fallback).
- **Cuerpo de texto**: Usar una fuente Sans-Serif limpia y muy legible (ej. 'Roboto', 'Open Sans' o sistema nativo).

## UI/UX
- Estilo corporativo, limpio, minimalista ("clean design").
- Espacios en blanco amplios (padding/margin) para facilitar la lectura.
- Botones con bordes ligeramente redondeados (2px - 4px) y efectos hover sutiles.

## Imágenes
- Deja hueco para las imágenes en la página web que luego rellenaré a mano con imagenes libres de derechos de autor.
